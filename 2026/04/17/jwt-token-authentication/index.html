概述

本文档详细介绍校园招聘管理平台中 JWT（JSON Web Token）认证机制的实现原理、核心组件和使用方式。

JWT 认证流程

核心技术组件

1. JwtTokenProvider

JwtTokenProvider 是 JWT 令牌的核心提供者，负责令牌的生成、验证和解析。

2. JwtAuthenticationFilter

JwtAuthenticationFilter 是 Spring Security 的过滤器，负责每个请求的 JWT 验证。

令牌结构

Access Token

存储的信息：

  • sub: 用户名
  • userId: 用户ID
  • role: 角色（包含 ROLE_ 前缀）
  • iat: 签发时间
  • exp: 过期时间

Refresh Token

与 Access Token 的区别：

  • 有效期更长（7天 vs 1小时）
  • 包含 type: "refresh" 声明
  • 存储在数据库中，支持令牌失效和续期
